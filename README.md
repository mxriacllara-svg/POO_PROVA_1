# POO_PROVA_1
Sistemas basico de controle de funcionarios, mostrando nome, cpf, departamento, cargo, salario e status do funcionario;

Java 21, Apache Netbeans IDE 30;

Deve ser inicializado, depois de aberto corretamente na sua IDE, dando apenas um click em run(play verde);

A classe Departamento tem a responsabilidade de armazenar o nome do departamento do funcionario;
A classe Cargo tem a responsabilidade de armazenar o nome do cargo do funcionario;
A classe Funcionario tem como responsabilidade criar e armazenar as informações dos funcionarios;
A classe TestaSistema tem com responsabilidade conter o main, que vai criar os objetos, alterar dados e imprimir as informações na tela;
